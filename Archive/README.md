# Project Archive

This folder stores historical revisions, superseded exports, and pre-repair builds.

## Directory structure

- **`2026-10-30/`**:
  - `Earlier-work/`: Early Blender assembly files, initial generator scripts, and reference images.
  - `Maintenance/`: Historical cleanup and preparation scripts.
  - `Superseded-share/`: Previous export packages (`Lamp-Snapmaker-U1.3mf` and `Lamp-TALLER-U1-3-shades.3mf`).
  - `Versions/`: Intermediate `.blend` models leading up to the taller cloud lamp.
- **`2026-11-03/`**:
  - `Broken-share-before-repair/`: Previous export files that contained XML namespace serialization errors (`ns0:` tags) prior to the 2026-11-03 repair.
